# Chocolate Sales Analysis

## Project Overview
This project presents a business performance analysis of a chocolate retail dataset using Microsoft Excel.  
The goal of this analysis is to identify revenue trends, profitability patterns, regional performance, and key business insights.


## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Cleaning Techniques
- Charts & Visualizations
- Conditional Formatting
- Business KPI Analysis


## Dataset Description
The dataset includes:
- Product categories
- Sales representatives
- Geographic regions
- Revenue & profit
- Units sold


## Key Analysis Performed
- Revenue analysis by region
- Profitability comparison
- Top-performing sales representatives
- Monthly sales trend analysis
- Cost vs Profit evaluation
- KPI Dashboard creation


## Key Insights
- Identified highest revenue-generating region
- Determined most profitable product category
- Found top-performing salesperson
- Analyzed seasonal sales trends


## Business Recommendations
- Focus marketing on high-performing regions
- Improve strategies in low-profit areas
- Optimize cost structure for better margins
- Incentivize top sales representatives


## Project Outcome
This project demonstrates strong Excel skills including data cleaning, structured modeling, and business-focused visualization.
